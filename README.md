# ✨ Gemini AI Suite: Telegram-бот + Веб-прокси (AI Studio / ChatGPT UI)

Универсальный мультимодальный комплекс на базе **Google Gemini API (`google-genai`)**, состоящий из двух независимых частей, которые могут работать одновременно:
1. **`bot.py`** — Telegram-бот с поддержкой всех форматов файлов, навигацией по чатам, выгрузкой кода и админ-мониторингом сервера каждые 10 минут.
2. **`web_app.py`** — Веб-приложение (прокси) в стиле **ChatGPT / Google AI Studio** с потоковой генерацией (Streaming), Drag & Drop файлов, записью голоса, Live-превью HTML-кода, Google Поиском и настройкой уровня размышлений (`Thinking Level`).

---

## 📁 Структура проекта

```text

```

## ⚡ Быстрый старт (Установка за 2 минуты)

### 1. Подготовка окружения (рекомендуется Python 3.10+)
Откройте терминал в папке проекта и создайте виртуальное окружение:

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация (Linux / macOS)
source venv/bin/activate

# Активация (Windows)
venv\Scripts\activate
```

### 2. Установка всех зависимостей одной командой
```bash
pip install --upgrade pip
pip install aiogram psutil fastapi uvicorn python-multipart "google-genai>=2.34.0"
```

## ⚙️ Что нужно поменять перед запуском

Вы можете задать настройки прямо внутри файлов `bot.py` и `web_app.py` (в блоке `⚙️ НАСТРОЙКИ` в самом верху) **или** передать их через переменные окружения.

### Настройки в `bot.py` (Telegram-бот):
| Переменная | Строка в коде | Что указать |
| :--- | :--- | :--- |
| `TELEGRAM_BOT_TOKEN` | `"ВАШ_ТОКЕН_ТЕЛЕГРАМ_БОТА"` | Токен от [@BotFather](https://t.me/BotFather) |
| `GEMINI_API_KEY` | `"ВАШ_КЛЮЧ_GEMINI_API"` | Ключ API из [Google AI Studio](https://aistudio.google.com/) |
| `ADMIN_IDS` | `[123456789]` | Ваш числовой Telegram ID (можно узнать в [@userinfobot](https://t.me/userinfobot)). Нужен для доступа к `/admin` и получения алертов «Серверу бо-бо» |
| `DEFAULT_MODEL` | `"gemini-4-hydrogen"` | Модель по умолчанию для новых пользователей |
| `HEALTH_CHECK_INTERVAL` | `600` | Интервал фоновой проверки сервера и API в секундах (`600` = 10 минут) |

### Настройки в `web_app.py` (Веб-сайт):
| Переменная | Строка в коде | Что указать |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | `"ВАШ_КЛЮЧ_GEMINI_API"` | Ключ API из Google AI Studio |
| `DEFAULT_MODEL` | `"gemini-4-hydrogen"` | Модель по умолчанию на сайте |
| `HOST` | `"0.0.0.0"` | Хост (`0.0.0.0` открывает доступ и локально, и по внешнему IP сервера) |
| `PORT` | `8000` | Порт, на котором открывается сайт |

> 💡 **Совет:** Чтобы не вписывать ключи в код, можно задать их в терминале перед запуском:
> ```bash
> export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
> export GEMINI_API_KEY="AIzaSy..."
> ```

## 🌐 На каких портах открывается сайт

По умолчанию веб-интерфейс (`web_app.py`) запускается на порту **`8000`**:

* **При запуске на своем ПК:** откройте в браузере 👉 **[http://localhost:8000](http://localhost:8000)** или **[http://127.0.0.1:8000](http://127.0.0.1:8000)**
* **При запуске на VPS / выделенном сервере:** откройте 👉 **`http://IP_ВАШЕГО_СЕРВЕРА:8000`**

*(Telegram-бот `bot.py` работает через Long Polling и **не требует** открытых входящих портов).*

### Как поменять порт сайта:
Измените переменную `PORT = 8000` в начале файла `web_app.py` на любой нужный (например, `8080` или `3000`).
Если на Linux-сервере включен файрвол `ufw`, не забудьте открыть выбранный порт:
```bash
sudo ufw allow 8000/tcp
```

## 🚀 Как запустить проект

### Вариант 1: Обычный запуск в терминале
Для запуска **Telegram-бота**:
```bash
python bot.py
```

Для запуска **Веб-сайта**:
```bash
python web_app.py
```

---

### Вариант 2: Фоновый запуск на сервере 24/7 (через `nohup`)
Если нужно быстро запустить оба скрипта на сервере, чтобы они не закрылись после выхода из SSH:

```bash
nohup ./venv/bin/python bot.py > bot.log 2>&1 &
nohup ./venv/bin/python web_app.py > web.log 2>&1 &
```
* Посмотреть логи: `tail -f bot.log` или `tail -f web.log`
* Остановить процессы: `pkill -f bot.py` и `pkill -f web_app.py`

---

### Вариант 3: Надежный автозапуск через `systemd` (Linux VPS)

Чтобы бот и сайт автоматически перезапускались при сбоях или перезагрузке сервера:

1. Создайте службу для бота `/etc/systemd/system/gemini-bot.service`:
```ini
[Unit]
Description=Gemini Telegram Bot
After=network.target

[Service]
User=root
WorkingDirectory=/путь/к/папке/проекта
ExecStart=/путь/к/папке/проекта/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

2. Создайте службу для сайта `/etc/systemd/system/gemini-web.service`:
```ini
[Unit]
Description=Gemini Web Proxy UI
After=network.target

[Service]
User=root
WorkingDirectory=/путь/к/папке/проекта
ExecStart=/путь/к/папке/проекта/venv/bin/python web_app.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

3. Активируйте и запустите обе службы:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now gemini-bot gemini-web
sudo systemctl status gemini-bot gemini-web
```

## 🛠 Полезные фишки и решение частых вопросов (FAQ)

### 1. Я поменял `DEFAULT_MODEL` в коде, но в боте/на сайте осталась старая модель
Модель сохраняется за каждым пользователем/чатом в базе данных при первом запуске.
* **Решение:** Либо переключите модель прямо в интерфейсе (кнопка `🤖 Выбор модели` в боте / выпадающий список сверху на сайте), либо удалите файлы БД (`rm gemini_bot.db gemini_web.db`) и перезапустите скрипт.

### 2. Как обновить список моделей при выходе новых версий Gemini?
* **В Telegram-боте:** Нажмите `🤖 Выбор модели` ➔ `🔄 Обновить список из API`.
* **На сайте:** Нажмите кнопку `🔄` рядом с выпадающим списком моделей в верхней шапке.

### 3. Как проверить, работает ли алерт «Серверу бо-бо» в Telegram?
Отправьте боту команду `/admin` (или нажмите кнопку `📊 Админ` внизу) и нажмите инлайн-кнопку **`🚨 Тест «Серверу бо-бо»`**. Там же можно временно отключить или включить 10-минутные уведомления.

### 4. Сколько хранятся загруженные тяжелые видео и аудио?
Текстовые файлы, код и история переписки хранятся в локальной базе SQLite **бессрочно**. Тяжелые медиафайлы (видео, аудио, PDF), загружаемые в облако через *Google Gemini File API*, хранятся на серверах Google **48 часов**, после чего автоматически пропускаются ботом/сайтом при сборке старого контекста, чтобы избежать ошибок API.
